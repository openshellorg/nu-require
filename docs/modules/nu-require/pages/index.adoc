= nu-require
:description: Require Nushell as the host shell for tailored CLIs.
:page-audience: Developers writing Nushell-tailored CLIs
:page-usage-context: Overview of the startup `validate()` gate, relaunch, and install offer
:page-last-author: cursor-agent on behalf of OpenShellOrg
:page-last-edited: 2026-09-29

`nu-require` is a small TypeScript library CLIs call at startup to require Nushell as the host shell.
It either continues under Nu, relaunches the same binary and argv via `nu -c`, or errors with an install path when `nu` is missing.
PowerShell is not an alternate supported host.

Nushell-tailored CLIs call `validate()` near process start:

[source,typescript]
----
import { validate } from "@openshellorg/nu-require";

await validate({ offerInstall: true });
----

Behavior:

. *Already under Nushell* → continue normally.
. *Not under Nushell, but `nu` is on PATH* → print that the tool is relaunching inside Nushell, then re-exec the same binary/argv via `nu -c`.
. *`nu` missing* → clear error, link to https://www.nushell.sh/, optionally offer a one-shot install when `offerInstall: true`.
